# Graffiti Tavi testing

Test files for XBRL International's [Project Tavi 1.0](https://www.xbrl.org/Specification/tavi/PWD-2026-09-01/tavi-PWD-2026-09-01.html)
Public Working Draft (1 September 2026), from S-Tech Analytics, the makers of [Graffiti](https://stechanalytics.com).

| Folder | What | Filings |
|---|---|---:|
| [`uk-pdf-tagging/`](uk-pdf-tagging/README.md) | 50 Companies House accounts printed to PDF and tagged blind by Graffiti, with every tag compared with the tags the companies filed | 50 |

The folder's README gives the results, what each file holds and how to score another tool on the same PDFs.
